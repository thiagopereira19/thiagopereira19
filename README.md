## 🚀 Featured project: PADIM'MUSIC

A full-stack music and podcast platform with accounts, playlists, a persistent player and a mobile-first layout.

**🔗 [Live demo](https://padimmusic.onrender.com)** · **📂 [Source code](https://github.com/thiagopereira19/padimmusic)**

> The API runs on a free tier, so the first load after a while may take up to a minute to wake up.

```
Browser (HTML / CSS / JavaScript)  →  REST API (Node.js + Express)  →  PostgreSQL (Aiven)
        Render Static Site                   Render Web Service
```

**What it does**
- Sign up and login with hashed passwords (bcrypt) and JWT sessions
- Per-user playlists: create, edit, delete and pick tracks
- Explore, follow and unfollow podcasts
- Trending chart for Brazil, search, and a player that keeps playing while you navigate
- Interface in 3 languages (Portuguese, English, Spanish)
- Responsive layout with a compact mobile header and mini-player

**Engineering details**
- Security: Helmet, rate limiting on auth routes, restricted CORS, parameterized SQL and per-user authorization on private routes
- An API proxy with in-memory caching fetches the third-party music chart, solving a browser CORS block
- Deployed with managed PostgreSQL on Aiven and the API plus static site on Render
- Responsive from 320 px phones up to tablets and desktop
